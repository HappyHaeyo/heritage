# 먼 곳의 유산 — 점에서 사진으로

## 현재 동작

첫 화면은 한국을 중앙에 둔 세계 전체 지도입니다. 수집 기록 21,474건을 9개국별 점 묶음으로 표시합니다.

- **점 하나 = 출처별 수집 기록 한 건**. 모든 국가에 같은 점 크기와 간격을 적용합니다.
- 국가 이름 또는 점 묶음을 누르면 해당 묶음을 확대합니다.
- 전체 지도에서는 휠로 확대합니다. 사진 화면에서는 휠·드래그·방향 버튼으로 이동하고, Ctrl+휠 또는 +/− 버튼으로 확대·축소합니다. 두 손가락 확대도 지원합니다.
- 충분히 확대하면 **같은 점의 같은 위치에 그 기록의 사진**이 나타납니다. 다시 축소하면 점으로 돌아갑니다.
- 사진 주소가 없거나 사진 연결에 실패한 기록은 점으로 남습니다. 확대된 점도 눌러서 기록을 읽을 수 있습니다.
- 사진을 누르면 기존 유물 상세 정보를 엽니다.
- ‘국가 기록 보기’에서 검색·출처 필터·사진 필터를 사용할 수 있습니다.
- ‘전체 보기’는 초기 분포 화면으로 돌아갑니다.
- 키보드로 지도에 초점을 둔 뒤 +/− 확대·축소, 방향키 이동, 0 전체 보기가 가능합니다.
- 반출·귀환 사례 7건은 기존 별도 화면에서 확인합니다. 외규장각 의궤는 국내 대여 상태로 구분합니다.

## 좌표와 수량의 의미

점은 국가별로 겹치지 않게 묶어 배치합니다. 가는 선은 **지도상의 국가 대표 위치와 점 묶음의 연결선**입니다. 이동 경로가 아닙니다. 개별 유물의 정확한 소장 위치나 박물관 좌표를 표현하지 않습니다.

확대 전후 기록의 대응은 고정됩니다. 각 국가 JSON의 레코드에 중앙부터 바깥쪽으로 고정된 격자 위치를 부여해, 전체 보기에서는 점으로, 확대 보기에서는 사진으로 표현합니다. 원본 JSON의 사진·설명이 있는 기록 우선 정렬을 유지하므로 첫 확대에서는 설명이 있는 유물을 먼저 만날 수 있습니다.

숫자는 이번에 수집한 **출처별 기록 수**입니다. 서로 다른 출처에 같은 유물이 중복되거나 하나의 기록이 여러 점·여러 책을 포함할 수 있습니다. 국가별 전체 보유량이나 약탈 규모를 뜻하지 않습니다. 사진 수 역시 전체 기록 수와 다릅니다.

사진은 기관 원본 URL에서 불러오며 인터넷 연결이 필요합니다. 이용 조건은 각 원문 페이지를 확인하세요.

## 실행

Node.js 22.14 이상을 설치한 뒤 다음 명령으로 실행합니다.

```sh
git clone https://github.com/HappyHaeyo/heritage.git
cd heritage
npm ci
npm run dev
```

브라우저에서 http://127.0.0.1:4175 를 엽니다. 화면용 데이터가 `public/data/`에 포함되어 있어 원본 수집 파일 없이 실행할 수 있습니다.
현재 PC에서는 `실행.cmd`를 더블클릭해도 됩니다. 이미 실행 중이면 위 주소에 접속하세요.

- `npm run build`: 배포용 dist 생성
- `npm test`: Edge에서 점·사진 전환, 같은 기록 연결, 휠 확대 기준점, 목록, 사진 없는 기록, 사례·대여 구분, 모바일 및 WebGL 대체 모드 검증
- `npm run prepare:data`: 아래에 명시한 별도 원본 수집 파일이 있을 때 화면용 JSON 재생성. 일반 실행에는 필요하지 않습니다.

현재 브라우저 검증 스크립트는 Windows 기본 설치 위치의 Microsoft Edge를 사용합니다. 먼저 `npm run dev`로 서버를 실행하고 별도 터미널에서 `npm test`를 실행하세요.

## UI 사용성 개선 (2026-10-02)

- 지도 위 국가 선택에서 확대 상태 그대로 다른 국가로 이동할 수 있습니다. 현재 국가의 전체 기록 수와 사진 주소 수를 함께 표시합니다.
- 확대·축소, 전체 보기, 국가 기록 보기 버튼을 지도 위에 두고 터치 영역을 확대했습니다.
- 사진을 크게 표시하고 마우스 또는 키보드 초점을 올리면 이름을 표시합니다. 사진 없는 국가에는 별도 안내를 표시합니다.
- 목록을 닫고 같은 국가의 기록을 다시 열면 검색 조건과 스크롤 위치가 유지됩니다. 적용된 조건은 필터를 접어도 보이며 바로 지울 수 있습니다.
- 목록에서 국가를 바꾸면 지도도 해당 국가로 이동합니다. 화면 크기 변경 시 탐색하던 지점을 유지합니다.
- 320px·390px 모바일 및 데스크톱 검증: `scripts/test-usability.mjs`. 수정 전 소스: `snapshots/before-ui-usability/`.

## 확대 후 탐색

확대 화면 옆(모바일에서는 위)에 해당 국가의 전체 기록 묶음을 계속 표시합니다. 현재 화면 범위는 청록색 사각형이며, 묶음을 클릭하거나 드래그하면 먼 영역으로 바로 이동합니다. 갈색 점은 사진 주소가 있는 기록, 흐린 점은 사진 주소가 없는 기록입니다. 방향 버튼은 한 화면의 80%만큼 이동합니다. 사진 화면에서 휠은 세로 이동, Shift+휠은 가로 이동, Ctrl+휠은 확대·축소입니다. 국가 전체 보기와 중심으로 돌아오기도 지원합니다. 사진 화면의 이동 범위는 해당 국가의 기록 끝으로 제한합니다.

검증: `scripts/test-navigation.mjs` — 휠 이동으로 기록 교체, 방향 버튼, 미니맵의 먼 영역 이동, 이동 후 상세 열기, 로딩된 사진 위 드래그, 모바일 조작.
